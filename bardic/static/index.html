    Advanced

    Gemini speech model, first audio, request lengths and limits

    Every book's Gemini narrator uses this model. Changing it starts new narration; audio from the earlier model stays saved.

    Copy the rate limits Google AI Studio shows for this model. Chapter audio requests are paced to them. The daily count covers only this library; other apps using the same Google project share the quota.

    Gemini caps one request at about 8.5 minutes of audio; Bardic plans at most 7.8. Quick-start lengths apply when Play starts generation; queued chapters use the full length.

    Troubleshooting

    Your library and audio stay on this device. Cloud analysis sends book text to your selected provider; Gemini narration sends text and performance notes to Google. Breeze narration sends passage text and performance notes to the server you configure on your local network, over plain HTTP unless its URL starts with https. Keys entered here stay in server memory and are never saved in this browser or written to .env. Cloud usage may incur charges.

    Troubleshooting log

    Playback and buffering issues are logged locally with passage and job IDs, playback speed, and error codes. Logs exclude book text and API keys. The most recent 5,000 events are retained.
